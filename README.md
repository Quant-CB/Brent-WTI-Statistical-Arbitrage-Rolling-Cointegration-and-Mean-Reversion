# Brent-WTI-Statistical-Arbitrage-Rolling-Cointegration-and-Mean-Reversion
Market-neutral statistical arbitrage on Brent–WTI crude oil futures: rolling OLS hedge ratio, z-score mean reversion and realistic costs. Validated with PSR, Monte Carlo and 32-fold walk-forward. No robust unconditional edge: profits appear only in cointegrated regimes.
